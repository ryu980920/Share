## 만들어야 할 것

### 1) 실행할 git 명령어

브랜치 생성 → add → commit → push 순서로. **한 줄씩 주석과 함께.**

- 브랜치 이름 규칙: `run/<RUN_ID>` 또는 여러 개면 `run/<담당자>-<열이름>` (예: `run/A-D24`)
- 커밋 메시지: 한국어 한 줄 + 필요시 본문
- ⚠️ `.tdr` `.plt` 같은 대용량 파일이 스테이징에 섞이지 않았는지 확인하는 명령도 포함할 것
  (예: `git status --short` 로 확인, `du -sh` 로 용량 체크)

### 2) PR 제목

`[담당자이니셜] 내용` 형식. 한 줄.

### 3) PR 본문

`.github/pull_request_template.md` 형식 그대로. 체크리스트를 실제로 판단해서 체크/미체크를 표시하고,
**판단할 수 없는 항목은 체크하지 말고 "확인 필요"로 표시해라.**

결과 요약 표는 내가 준 숫자로만 채운다. 안 준 격자점은 빈 행으로 남긴다.

### 4) 마지막 경고

아래 중 해당하는 게 있으면 PR 을 올리기 전에 반드시 알려라.

- `metrics.csv` 를 손으로 만든 정황
- Run ID 와 `run.yaml` 값 불일치
- `baseline/` 변경이 포함됐는데 리뷰어가 1명으로 되어 있음
- 대용량 파일이 커밋에 포함됨
