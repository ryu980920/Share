# 프로젝트 컨텍스트 — 반드시 이 규칙을 지켜서 답할 것

너는 지금 반도체 TCAD 공동연구 팀의 작업을 돕고 있다.
아래 규칙은 **3명의 팀원이 각자 다른 AI 를 써도 결과물 형식이 동일해야 하기 때문에** 존재한다.
형식을 임의로 "개선"하지 마라. 형식이 어긋나면 자동 병합 스크립트가 깨진다.

## 1. 연구 개요

- **주제**: DRAM BCAT(Buried Channel Array Transistor)의 두 설계 변수를 2차원으로 함께 스윕해, GIDL(Gate-Induced Drain Leakage)에 대한 상호작용을 규명한다.
- **변수 X**: `DBCAT` — 금속 게이트 위 질화막 두께 [nm]. 두꺼울수록 게이트가 깊이 묻혀 게이트-드레인 겹침이 줄고 GIDL 이 감소한다.
- **변수 Y**: `doping_multiplier` — Elevated S/D 접합 도핑 농도의 베이스라인 대비 배수 [-]. 낮출수록 접합 전계가 약해져 GIDL 이 감소한다.
- **핵심 질문**: 두 변수가 독립인가, 시너지인가, 트레이드오프인가.
- **도구**: Synopsys Sentaurus TCAD (SDE + SDevice)
- **베이스라인 논문**: Kim et al., Micromachines 2022, 13(9), 1476

## 2. DoE 격자 (5 × 5 = 25점)

- DBCAT: `24, 30, 36, 42, 48` nm (공칭 36)
- 도핑 배수: `0.30, 0.50, 0.70, 0.85, 1.00`
- 베이스라인 격자점: `D36_N100`

## 3. Run ID 명명 규칙 — 절대 변경 금지

```
D{DBCAT정수}_N{도핑배수×100을 3자리로}
```

예: `D24_N030`, `D36_N100`, `D48_N085`
부가 실험은 접미사: `D36_N100_hurkx`, `D36_N100_mesh_fine`

## 4. 폴더·파일 구조 — 절대 변경 금지

```
runs/<RUN_ID>/
  run.yaml       메타데이터
  idvg.csv       원시 Id-Vg. 컬럼은 정확히  Vg,Id_lin,Id_sat  (대소문자 구분)
  metrics.csv    지표. ★ 사람이나 AI 가 만들지 않는다. extract.py 만 생성한다
  plot.png       Id-Vg 플롯
  README.md      3줄 요약
```

- `Vg` : 게이트 전압 [V], -1.0 ~ +2.8, 0.05 V 간격
- `Id_lin` : Vd = 0.1 V 에서의 드레인 전류 [A/µm]
- `Id_sat` : Vd = 1.0 V 에서의 드레인 전류 [A/µm]

## 5. 지표 이름 — 이 이름만 쓴다

`Vth_lin_V`, `Vth_sat_V`, `SS_mV_dec`, `DIBL_mV_V`, `I_GIDL_A_um`,
`Ion_A_um`, `Ioff_A_um`, `Ion_Ioff_ratio`

## 6. 브랜치·PR 규칙

- 브랜치: `run/D36_N100`, `fix/baseline-mesh`, `docs/devlog-0810`
- PR 제목: `[담당자이니셜] 내용`  예) `[A] D24 열 5점 완료`
- `baseline/` 수정은 리뷰어 2명, 그 외는 1명

## 7. 커밋 금지 파일

`.tdr` `.grd` `.dat` `.plt` `.bnd` 원본, Workbench 프로젝트 폴더 전체.
용량이 커서 저장소가 망가진다. 추출한 `idvg.csv` 만 올린다.

## 8. ★★ 절대 지켜야 할 것 ★★

1. **수치를 절대 지어내지 마라.** Vth, GIDL, Ion 같은 값은 내가 실제 출력을 붙여넣어야만 채운다.
   내가 값을 안 줬으면 **빈칸으로 두고, 무엇이 필요한지 물어봐라.** "예시 값"을 넣지 마라.
2. **`metrics.csv` 를 직접 작성하지 마라.** 그건 `analysis/extract.py` 가 만든다.
   내가 지표를 물으면 실행할 명령어를 알려줘라.
3. **파일명·컬럼명·지표명을 바꾸지 마라.** 더 나은 이름이 떠올라도 위 규칙을 그대로 써라.
4. **한국어로 답하라.** 코드·파일명·명령어는 영문 그대로.
5. 확실하지 않으면 추측하지 말고 **모른다고 말하고 무엇을 확인해야 하는지 알려줘라.**
