# prompts/ — 팀원용 AI 프롬프트

## 왜 이게 필요한가

3명이 각자 다른 AI(ChatGPT / Claude / Gemini)를 쓰면서 "결과 정리해줘"라고 하면
**셋 다 다른 형식으로 나온다.** 폴더 이름이 다르고, 컬럼 이름이 다르고,
Vth 를 다르게 계산한다. 그러면 `merge.py` 가 격자를 못 만든다.

여기 있는 프롬프트는 **AI 에게 우리 저장소의 규칙을 강제로 주입**해서,
누가 어떤 AI 를 쓰든 같은 형식이 나오게 만든다.

---

## 사용법 — 딱 두 단계

### 1단계. 대화를 시작할 때 `00_공통컨텍스트.md` 를 통째로 붙여넣는다

이걸 안 붙이면 AI 는 우리 규칙을 모른다. **매 대화 처음에 한 번씩.**

> ChatGPT 를 쓴다면 → "Custom Instructions" 나 Project 지식에 넣어두면 매번 안 붙여도 된다.
> Claude 를 쓴다면 → Project 의 지식(Knowledge)에 넣어둔다.
> Claude Code 를 쓴다면 → 저장소 루트의 `CLAUDE.md` 가 자동으로 읽히므로 아무것도 안 해도 된다.

### 2단계. 하려는 일에 맞는 프롬프트를 골라 이어서 붙인다

| 상황 | 프롬프트 |
|---|---|
| 시뮬레이션이 끝났다. 결과를 저장소 형식으로 정리하고 싶다 | `01_결과정리.md` |
| 정리한 결과를 커밋하고 PR 을 올리고 싶다 | `02_업로드_PR.md` |
| 새 과제 Issue 를 만들고 싶다 | `03_이슈작성.md` |
| 에러가 났다. 팀에 물어볼 질문을 만들고 싶다 | `04_트러블슈팅.md` |
| 등고선·회귀 결과를 해석하고 발표 문장을 만들고 싶다 | `05_결과해석.md` |
| 코드 변경분을 팀에 설명하고 싶다 | `06_코드변경설명.md` |

## 절대 규칙 (프롬프트 안에도 들어 있지만 다시 강조)

> **AI 에게 숫자를 만들게 하지 않는다.**
>
> 시뮬레이션 값, Vth, GIDL 같은 수치를 AI 가 "예시로" 채워넣은 것을 그대로 커밋하면
> 그 격자점은 조작된 데이터가 된다. 발표에서 이게 드러나면 프로젝트 전체가 무효다.
>
> 프롬프트에 "값을 모르면 빈칸으로 두고 물어보라"는 지시가 들어 있지만,
> **최종 확인은 사람이 한다.** 커밋 전에 숫자가 실제 출력과 같은지 반드시 눈으로 대조할 것.
