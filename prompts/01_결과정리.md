## 만들어야 할 것

### 1) `runs/<RUN_ID>/run.yaml`

`runs/_template/run.yaml` 형식 그대로. **내가 안 준 값은 빈칸으로 두고 무엇이 필요한지 물어라.**

### 2) `runs/<RUN_ID>/README.md`

정확히 아래 형식. 각 항목 **2줄 이내**.

```markdown
# <RUN_ID>

## 무엇을 바꿨나
(baseline 대비 DBCAT ___ nm, 도핑 ×___. 그 외 변경 없음/있음)

## 무엇이 나왔나
(핵심 숫자 1개. 예: GIDL = 3.2e-12 A/um, baseline 대비 -58%)

## 이상한 점 / 의심되는 점
(없으면 "없음")
```

### 3) 검증 체크

아래를 확인하고 **문제가 있으면 지적해라. 조용히 넘어가지 마라.**

- [ ] Run ID 의 D/N 값과 `run.yaml` 의 `D_BCAT_nm` / `doping_multiplier` 가 일치하는가
- [ ] `metrics.csv` 에 `nan` 이 있는가 → 있으면 어느 지표이고 원인이 뭘 가능성이 높은지
- [ ] `I_GIDL_A_um` 이 물리적으로 말이 되는 범위인가 (보통 1e-15 ~ 1e-9 A/µm)
- [ ] `Ion_A_um` 이 1e-1 A/µm 을 넘는가 → 넘으면 폭 정규화(A/µm) 누락 의심
- [ ] `Vth_sat_V` 가 baseline 대비 ±0.2 V 를 벗어나는가

**내가 준 숫자만 쓴다. 없는 값은 채우지 말고 물어봐라.**
